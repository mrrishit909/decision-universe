# Data contracts

The site consumes only `site/public/data/*.json`, validated against `data/contracts/<name>.schema.json` (JSON Schema 2020-12, generated by `pipelines/contracts.py`, the single source of truth). Every artifact: `schema_version: "v1"`, `generated_at` (fixed stamp so builds are byte-identical), a `tags` map (field group to honesty tag), compact sorted-key JSON, no NaN or infinity (missing is `null`). Each artifact is under 400 KB gzip; sizes are written to `meta.json.artifact_bytes`.

Tags: OBSERVED / DERIVED / PREDICTED / SIMULATED / SYNTHETIC and "/" combinations.

## Parity rule
Every module artifact carries `tolerance {abs, rel}`: a port passes when `|got - want| <= abs + rel*|want|`. Numbers are published rounded half-up to 10 decimals (`floor(x*1e10+0.5)/1e10`). Integers (PRNG outputs, counts) must match exactly. Algorithms the port must implement are specified in `docs/METHODOLOGY.md`; the vectors list inputs, seeds and outputs.
