# Decision Universe

Every Decision Creates a Different Future. Ten decision-science modules (distributions, sampling, Monte Carlo, Bayes, forecast intervals, cost-sensitive thresholds, LP/Pareto, sensitivity, counterfactuals, causal inference) with Python reference implementations, parity vectors and real datasets (NSW/PSID, German Credit) for a browser-side TypeScript port.

    uv sync && uv run python -m pipelines.run_all && uv run pytest -q

See `docs/` (PROBLEM, DATA_SOURCES, DATA_CONTRACTS, METHODOLOGY, LIMITATIONS, TESTING). NSW data: NBER, attributable non-commercial use; derived results only.
